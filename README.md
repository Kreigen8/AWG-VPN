# AWG VPN

Нативное Android-приложение для собственных конфигураций AmneziaWG 2.0 и 3.1. Минимальная версия — Android 10 (API 29). Для подключения нужен действующий конфиг вашего VPN-сервера.

## Установка и обновление

Подписанный APK находится в [GitHub Releases](https://github.com/Kreigen8/AWG-VPN/releases). Скачайте APK на телефон и установите **поверх существующего AWG VPN**. Удалять старое приложение не требуется: конфиги, выбранные приложения и активный профиль сохраняются. Пакет `ru.routevpn.app` и ключ подписи прежние.

Автовосстановление применяется к подключению, которое вы включили в этой версии. Для настройки системного запуска: «Подключение» → «Автозапуск: настройки VPN Android» → AWG VPN → «Постоянная VPN». Блокировка соединений без VPN мешает приложениям, выбранным для прямого доступа, поэтому её следует включать только осознанно.

Плитку добавьте кнопкой «Добавить VPN в шторку» или через редактирование шторки Android. Плитка использует выбранный профиль; если Android требует разрешение VPN, откроется приложение с системным запросом. Права на показ поверх других приложений не нужны.

В редакторе основные поля изменяют первый раздел `[Peer]`; остальные серверы и параметры AmneziaWG доступны в полном тексте. Полный текст содержит приватный ключ. Черновик переживает поворот экрана в памяти; после завершения процесса несохранённые изменения не восстанавливаются. Одна предыдущая сохранённая версия хранится зашифрованной вместе с профилем.

## Возможности

- Несколько профилей, импорт `.conf` и вставка текста.
- Полноэкранный редактор: сервер, порт, DNS и MTU, а также полный текст .conf. Проверка перед сохранением, отмена правок и одна предыдущая сохранённая версия. Имя профиля и правила приложений сохраняются.
- Создание профиля из QR-кода: камерой или из изображения. Распознавание работает на устройстве.
- Три режима для каждого профиля: все приложения через VPN; только выбранные через VPN; выбранные напрямую, остальные через VPN.
- Поиск приложений по названию и имени пакета, просмотр системных приложений.
- Статус ответа сервера, счётчики трафика, отключение из уведомления.
- Восстановление после смены сети, перезапуска процесса и возвращения сети; ручное отключение запоминается. Поддержка системного Always-on.
- Кнопка AWG VPN в шторке Android для выбранного профиля.
- Конфиги зашифрованы AES-GCM; ключ хранится в Android Keystore. Резервное копирование конфигов средствами Android отключено.

QR может содержать обычный текст `.conf` или локальную ссылку `vpn://` с одним готовым профилем AmneziaWG. Подписки, интернет-ссылки и составные анимированные QR в этой версии не поддерживаются; приложение предлагает экспортировать отдельный `.conf` или обычный QR. Содержимое QR не загружается из сети.

## Использование

1. Установите APK на телефон и откройте AWG VPN.
2. Нажмите «Импортировать» и выберите файл, текст, камеру или изображение QR-кода.
3. Выберите режим маршрутизации и нужные приложения.
4. Нажмите «Подключить VPN» и подтвердите системное разрешение Android. Разрешение на уведомления желательно для удобного отключения.
5. Для изменения правил отключите VPN, сохраните изменения и подключитесь снова.

Чтобы изменить параметры сервера в сохранённом профиле, отключите VPN и выберите «Изменить» → «Редактировать конфиг». Исправьте текст и сохраните его: приложение сначала проверит конфигурацию, сохранив имя профиля и его правила приложений.

Режим «Только выбранные через VPN» не включается с пустым списком. Если выбранное приложение удалено, список нужно обновить перед подключением. Правила относятся к приложениям текущего профиля Android.

Сетевые маршруты `AllowedIPs` сохраняются из конфига. Для всего интернет-трафика обычно нужны `0.0.0.0/0` и, если сервер поддерживает IPv6, `::/0`. Приложение не подменяет параметры сервера автоматически. При включённой системной настройке Android «Блокировать соединения без VPN» приложения, направленные в обход VPN, не получат доступ к сети.

Состояние «VPN подключён» появляется после подтверждённого обмена ключами с сервером. Поднятие локального интерфейса само по себе не считается успешным подключением. Включённое подключение восстанавливается автоматически, если разрешено автовосстановление. Для системного запуска после перезагрузки используйте «Постоянная VPN» в настройках Android. Приложение не обходит запрет Android на запуск после принудительной остановки.

## Сборка

Проект содержит исходники приложения, официальный Java-модуль AmneziaWG и готовые нативные библиотеки из проверенного официального релиза. Происхождение, версии и контрольные суммы описаны в `vendor/PROVENANCE.md`; лицензии находятся в `vendor/licenses/` и включены в APK.

На Windows с локальным комплектом инструментов:

```powershell
.\scripts\setup.ps1 -AcceptSdkLicenses
.\scripts\build.ps1 -Tasks @('assembleDebug', 'testDebugUnitTest', 'lintDebug')
```

Параметр `-AcceptSdkLicenses` принимает лицензии Android SDK; без него установщик предложит ознакомиться с ними интерактивно. Скрипт устанавливает переносимые JDK 17, Gradle и Android SDK в папки проекта, не меняя системные установки.

В Android Studio откройте корень проекта и используйте JDK 17 / SDK 35. Секреты подписания находятся отдельно в локальной `.signing/` и не включаются в архив исходников. Сохраните эту папку в защищённой резервной копии: она нужна для выпуска обновлений поверх установленного APK. Установка APK, подписанного другим ключом, потребует удаления предыдущего приложения вместе с его данными.

Версия `0.2.0-preview` добавляет подключение по схеме официального AmneziaWG, автовосстановление, системный Always-on, полноэкранный редактор и плитку в шторке. Изученные исходники и отличия описаны в [docs/UPSTREAM-CONNECTION.md](docs/UPSTREAM-CONNECTION.md). Обновление подписано тем же ключом и устанавливается поверх предыдущих версий с сохранением профилей.

Автоматические тесты проверяют совместимость конфигов, сохранение параметров протокола, маршрутизацию, обработку QR и запуск экрана сканера. Проверка подключения к реальному серверу, физической камеры, Android Keystore и фоновой работы требует телефона и действующего конфига; эти проверки нельзя заменить успешной компиляцией или тестами среды Android.
